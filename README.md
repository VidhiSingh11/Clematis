Clematis - Mental Health & Wellness Platform

 Overview

Clematis is a responsive front-end web application dedicated to mental health awareness and resource accessibility. The platform serves as a digital sanctuary, offering users easy access to therapy resources, mental wellness articles, and self-care tools through an intuitive and calming user interface.

The project emphasizes User Experience (UX) design principles, ensuring accessibility across devices through a mobile-first approach.

 Key Features

Responsive Design: Fully adaptable layout for Mobile, Tablet, and Desktop devices using Bootstrap Grid System.

Interactive UI: Dynamic navigation and smooth transitions implemented with JavaScript and CSS Animations.

Resource Hub: Structured content sections for articles, helpline numbers, and therapy connections.

Appointment Interface: A frontend form design for scheduling consultations with mental health professionals.

🛠 Tech Stack

Structure: HTML5 (Semantic)

Styling: CSS3, Bootstrap 5

Interactivity: JavaScript (ES6)

Icons: FontAwesome / Bootstrap Icons



Launch:
Open index.html in any modern web browser (Chrome, Edge, Firefox).
